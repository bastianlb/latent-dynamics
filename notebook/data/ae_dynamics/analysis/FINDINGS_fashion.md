# AE latent-dynamics grid on Fashion-MNIST: replication of FINDINGS.md (mean ± sd over 3 seeds)

Setup: identical 48-run grid and hyper-parameters as MNIST (mlp 784-256-64-d, Adam lr1e-3, bs128, 20k steps, 120 log snapshots, coupled-L2 wd), run via `run_ae_grid.py --dataset fashion_mnist`
-> `ae_dynamics/runs/fashion_mnist_ae_{mlp|linear}_d{D}_s{seed}_n{N}_wd{wd}` (48/48 ok). Matched classifier runs EXIST (`runs_v2/runs/fashion_mnist_probe_none_d16_s{0,1,2}_phase_n{250,1000,4000,full}_wd{0,1e-4}`, 24 runs, same hparams, config.json checked) and are included. No new classifier training.
Outputs (MNIST outputs untouched): `analysis/fashion/` = runs/, memorization/, figures/ (generalization_vs_N, gen_timeseries, probe_vs_ae, d_sweep, staging_pc_rise, bars_final, ts_*), summary*.csv/md,
`findings_stats_fashion.txt` (all numbers below) and `findings_stats_mnist_same_method.txt` (same script on MNIST, reproduces the FINDINGS.md numbers; script: /homes/lbastian/latent-dynamics/ae_findings_stats.py). The MNIST-only `findings_*.png` composites were made ad hoc and were not regenerated for Fashion.
Epoch = step*128/N. Gap onset = first snapshot with test/train-1 > 10%. "Rel gap" = te/tr-1.

REPLICATES.

- Test minimum then rise: min at epoch 152±9 (N=250, step 296±17), 155±10 (N=1000, step 1207±77), 186±21 (N=4000, step 5803±650) (MNIST 123/122/227). ## 3. Does geometry track the gap beyond N?
Partial correlation (regress out log N and wd; MLP d16, 24 runs; N<=4000 subset in parentheses; this uses a simpler 3-covariate adjustment than the original, so the same script was rerun on MNIST for comparison): spread_lab Fashion +0.20 (-0.39) vs MNIST +0.75 (+0.21); var +0.32 (-0.18) vs +0.82 (+0.46); white-var +0.45 (-0.36) vs +0.84 (+0.36); NN ratio -0.96 (-0.92) vs -0.87 (-0.84); CKA-to-PCA +0.71 (+0.65) vs +0.44 (+0.59); eff-rank-ratio -0.07 (-0.50) vs 0.00 (-0.30). Spread/var signs flip between datasets and between the all-N and N<=4000 subsets, so no robust signal (consistent with "nothing beats log N"). NN ratio and CKA are large and same-sign on BOTH datasets under this crude adjustment, but only 8 configs (6 for N<=4000) and N=250 is a nonlinear outlier, so this cannot be separated from N; flag for a follow-up (the original MNIST analysis had not used nn_ratio). Verdict PARTIALLY (null for spread/var; nn_ratio unresolved).

## Caveats
3 seeds, 8 MLP configs; N=250 rel gaps noisy (sd ~25%). The d16 pixel-PCA reference for Fashion was computed on probe images only at d16. Fashion test/train baseline is ~0 (linear full -0.5%/+0.08% rel), unlike MNIST's -1.6%, so the 'excess over baseline' correction is not needed here. Partial-correlation adjustments here are cruder than the MNIST write-up's (compare only via the same-method MNIST rerun). Test-min epochs quantised by log snapshots (~9%).
